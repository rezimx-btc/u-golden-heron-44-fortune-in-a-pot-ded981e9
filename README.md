# Fortune in a Pot

Entry for the make.fun bounty "Fortune in a Pot"
(https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9).

One kind, funny fortune for a houseplant, in 120 characters or fewer:
a small rebellion against the care tag, rewarded by the universe.

![A cheerful potted houseplant on a sunny windowsill](fortune.png)

`main.py` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). It refuses to emit anything longer than
120 characters. No network, no randomness — both runs write identical bytes.

## Run it

```sh
python3 main.py
```

Python 3.13, stdlib only. Output: `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).
